# Vela - Fullstack Project

Dự án Vela bao gồm:
- **`vela-fe`**: Frontend xây dựng với React + Vite.
- **`vela-be`**: Backend xây dựng với Spring Boot 3 (Java 21) + Maven + PostgreSQL.

## Cấu trúc thư mục

```
vela/
├── vela-fe/   # Frontend (React + Vite)
└── vela-be/   # Backend (Spring Boot 3 + Maven)
```

## Khởi chạy

### Frontend:
```bash
cd vela-fe
npm install
npm run dev
```

### Backend:
```bash
cd vela-be
./mvnw spring-boot:run
```
